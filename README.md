# Netino (نتینو) — کلاینت VPN اندروید · نسخه 2.0.3

## تغییرات 2.0.3
- **رفع کرش‌ها**: خطاهای کارهای پس‌زمینه دیگر برنامه را نمی‌بندند؛ ذخیره‌سازی رمزنگاری‌شده در خطای گذرای Keystore (سامسونگ) کرش نمی‌کند و داده را پاک نمی‌کند؛ شروع و توقف سرویس‌های پیش‌زمینه (وایرگارد و Xray) بدون حالت مسابقه و سازگار با قوانین اندروید ۱۵/۱۶. علت هر کرش بعدی در «گزارش لحظه‌ای» ثبت می‌شود و دکمهٔ «کپی گزارش» دارد.
- **کانفیگ‌های allowInsecure** (TLS با گواهی خودامضا) که در Xray 26 کلاً رد می‌شدند، حالا با پین کردن گواهی سرور وصل می‌شوند و کنار نامشان «ناامن» نوشته می‌شود (همین‌طور کانفیگ‌های بدون رمزنگاری TLS).
- **اتصال به سریع‌ترین سرور**: انتخاب محدوده (همه، سرورهای من، یک اشتراک یا یک گروه) و تست سرعت واقعی؛ اگر سروری پینگ خوب ولی سرعت نداشت، سرور بعدی امتحان می‌شود.
- **آپدیت درون‌برنامه‌ای**: کنار نام نتینو «آپدیت آمده» نمایش داده می‌شود؛ APK مناسب گوشی دانلود، checksum بررسی و نصب‌کننده باز می‌شود.
- **گروه‌های دلخواه** برای سرورها، **جستجو در نوار بالا**، **باز/بسته ماندن دائمی بخش‌ها**، **صفحهٔ افزودن شبکه‌ای**، **شناخت کانفیگ‌های JSON** (Xray، sing-box، اشتراک JSON) در همان «چسباندن» و «ورود دستی».
- دکمهٔ اتصال فقط رنگ عوض می‌کند و در حالت وصل فقط هالهٔ سبز اطرافش آرام کم و زیاد می‌شود.

## تغییرات 2.0.2
- **مرتب‌سازی بر اساس تأخیر واقعی** به‌صورت پیش‌فرض (و ذخیره‌شده): اول سرورهایی که تست واقعی دارند، از کم به زیاد. نتیجهٔ پینگ‌ها بعد از به‌روزرسانی اشتراک حفظ می‌شود.
- **نمایش حجم و روزِ باقی‌ماندهٔ اشتراک** (مثل v2box) از هدر `subscription-userinfo` پنل، با نوار پیشرفت.
- **به‌روزرسانی خودکار اشتراک**: خاموش، هر ۱، ۶، ۱۲ یا ۲۴ ساعت، برای هر اشتراک جدا (WorkManager، حتی وقتی برنامه بسته است).
- **اشتراک داخلی «نتینو»**: همیشه فعال و غیرقابل حذف. محتوایش را `.github/workflows/configs.yml` می‌سازد (پایین‌تر).
- **ورود فایل‌های وایرگارد**: انتخاب چندتایی فایل‌های `.conf` (و فایل `.zip` خروجی برنامهٔ WireGuard)، و «اشتراک‌گذاری» فایل به نتینو از فایل‌منیجر یا تلگرام. نام سرور = نام فایل.
- **بهینه‌سازی وایرگارد**: حذف کلیدهای مخصوص wg-quick (PostUp و …)، تشخیص AmneziaWG، MTU قابل تنظیم (پیش‌فرض ۱۲۸۰)، PersistentKeepalive خودکار، و گزارش هندشیک در گزارش لحظه‌ای.

## اشتراک داخلی و جمع‌آوری خودکار کانفیگ
`tools/collector/collector.py` روی GitHub Actions اجرا می‌شود و نتیجه را در شاخهٔ `configs` منتشر می‌کند
(`https://raw.githubusercontent.com/az09rez/netino/configs/sub.txt`، با پشتیبان jsDelivr):
- **هر ۲ ساعت**: همهٔ کانفیگ‌های فعلی دوباره تست می‌شوند و هر کدام قطع باشد حذف می‌شود.
- **هر روز**: منابع عمومی (`tools/collector/sources.txt`، لینک اشتراک یا کانال عمومی تلگرام) جستجو می‌شوند و کانفیگ‌های جدیدِ سالم اضافه می‌شوند.
- هر کانفیگ باید دو تست را پاس کند: **تأخیر واقعی** (درخواست HTTP از داخل خود کانفیگ با هستهٔ Xray روی سرور GitHub) و **دسترسی از ایران** (اتصال TCP از نودهای ایرانی check-host.net؛ دامنه هم در ایران resolve می‌شود). لیست بر اساس پینگ از ایران مرتب می‌شود.
- محدودیت: سرورهای GitHub در ایران نیستند، پس «تأخیر واقعی» از خارج سنجیده می‌شود و از ایران فقط باز بودن مسیر TCP و پینگ آن. فیلترینگ مبتنی بر SNI یا DPI را این تست نمی‌بیند.
- این کانفیگ‌ها عمومی و ناشناس‌اند؛ برای کارهای حساس از سرور شخصی استفاده کنید.
- اجرای دستی: Actions → Built-in configs → Run workflow. GitHub زمان‌بندی‌ها را در مخزنی که ۶۰ روز فعالیت نداشته باشد متوقف می‌کند.

## تغییرات 2.0.1
- **موتور تونل hev-socks5-tunnel** (همان موتور پیش‌فرض v2rayNG) به‌عنوان پیش‌فرض اضافه شد: TUN → hev → SOCKS5 محلی با نام کاربری و رمز تصادفی → Xray. موتور Xray TUN هم در تنظیمات قابل انتخاب است (در اندروید ۸ و ۹ خودکار استفاده می‌شود).
- مسیریابی پیش‌فرض `AsIs` شد: دامنه‌ها بدون نیاز به DNS مستقیم به سرور فرستاده می‌شوند، مثل NPV و v2rayNG.
- **انتخاب سریع‌ترین سرور فقط بر اساس تأخیر واقعی** انجام می‌شود (پینگ TCP فقط برای کنار گذاشتن سرورهای خاموش است). اگر هیچ سروری از تست واقعی رد نشود، هیچ سروری انتخاب نمی‌شود.
- خطای دقیق هسته برای هر تست ناموفق در تب «مصرف»، بخش گزارش لحظه‌ای، نوشته می‌شود.
- پنل باز و بسته‌شونده برای هر اشتراک، با بهترین پینگ، نقطهٔ «متصل»، و منوی تست، به‌روزرسانی و حذف.
- اسکنر QR در حالت عمودی قفل شد (دیگر گوشی نمی‌چرخد) و گزینهٔ خواندن QR از تصویر گالری اضافه شد.

کلاینت سبک، بدون تبلیغات و بدون ردیابی برای **Xray/V2Ray** (VLESS، VMess، Trojan، Shadowsocks، Reality، Hysteria2، SOCKS) و **WireGuard**.
شناسهٔ بسته: `com.netino.vpn`

## امنیت و حریم خصوصی
- همهٔ کانفیگ‌ها و کلیدها با AES-256-GCM و کلید محافظت‌شدهٔ اندروید (Keystore) رمز می‌شوند. بکاپ ابری خاموش است.
- DNS-over-HTTPS از داخل تونل، و جلوگیری از نشت IPv6.
- اختیاری: مخفی کردن محتوای برنامه در لیست برنامه‌های اخیر (FLAG_SECURE).
- لینک کپی‌شده به‌عنوان «حساس» علامت می‌خورد تا در پیش‌نمایش کلیپ‌بورد نمایش داده نشود.
- بدون access log، بدون آنالیتیکس، بدون تبلیغات. اثرانگشت TLS مرورگر Chrome (uTLS) و پشتیبانی از Reality و XTLS-Vision.
- Kill Switch از «VPN همیشه روشن» خود اندروید استفاده می‌کند.

## ساخت (Build)
1. فایل `libv2ray.aar` (نسخهٔ فعلی: v26.9.30) را از [AndroidLibXrayLite](https://github.com/2dust/AndroidLibXrayLite/releases) و فایل `hev-socks5-tunnel.aar` (نسخهٔ فعلی: 2.18.0) را از [hev-socks5-tunnel](https://github.com/heiher/hev-socks5-tunnel/releases) در `app/libs/` بگذارید.
2. (اختیاری) فایل‌های `geoip.dat` و `geosite.dat` را در `app/src/main/assets/` بگذارید.
3. این دستور را اجرا کنید: `gradlew assembleRelease`. APKها در `app/build/outputs/apk/release/` ساخته می‌شوند.
   کلید امضا در `keystore/` و `keystore.properties` است. این دو را نگه دارید، چون آپدیت‌های بعدی فقط با همین کلید نصب می‌شوند.

### ساخت خودکار در GitHub Actions
با هر push، فایل `.github/workflows/build.yml` APKها را می‌سازد و در صفحهٔ اجرای workflow (بخش **Artifacts**) می‌گذارد.
- اگر Secretهای زیر تعریف شده باشند، APK با کلید اصلی امضا می‌شود (`release`)؛ وگرنه نسخهٔ `debug` ساخته می‌شود که فقط برای تست است و روی نسخهٔ نصب‌شده آپدیت نمی‌شود.
- وقتی `versionName` در `app/build.gradle.kts` عوض شود و به `main` برسد، APKهای امضاشده خودکار در بخش **Releases** با تگ `v<نسخه>` منتشر می‌شوند (push یک تگ `v*` هم همین کار را می‌کند).

Secretها (Settings → Secrets and variables → Actions → New repository secret):

| نام | مقدار |
|---|---|
| `KEYSTORE_BASE64` | فایل `.jks` به صورت Base64 |
| `KEYSTORE_PASSWORD` | `storePassword` از `keystore.properties` |
| `KEY_ALIAS` | `keyAlias` |
| `KEY_PASSWORD` | `keyPassword` |

برای گرفتن Base64 در ویندوز (PowerShell، داخل پوشهٔ پروژه؛ نام فایل `.jks` را با `dir -r *.jks` پیدا کنید):
```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes((Resolve-Path "app\keystore\netino.jks"))) | Out-File keystore.b64 -Encoding ascii
notepad keystore.b64
```
همهٔ متن داخل Notepad را (Ctrl+A، Ctrl+C) در Secret بگذارید و بعد فایل `keystore.b64` را پاک کنید.
